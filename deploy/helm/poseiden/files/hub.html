Single tenant, everyone is the default owner

Auth is off in the playground, so every request maps to the shared default tenant, where the demo data lives. To exercise multi-tenant isolation, redeploy with auth.enabled=true and a provider, then sign in as different users.

Cheatsheet

# open the playground (build, deploy, seed, open)
POSEIDEN_VALUES=deploy/helm/poseiden/ci/minikube-localhost-values.yaml ./poseiden.sh up

# headless stack test: chart + image + stub provider + tenant isolation
./poseiden.sh verify

# show what is running
./poseiden.sh status

# tear it down (also stops the ingress forward)
./poseiden.sh down

Served on your machine only, by the chart's templates/localhost.yaml. Reachable via poseiden.sh's ingress forward on port 80; *.localhost resolves to 127.0.0.1 in Chrome and Edge.
