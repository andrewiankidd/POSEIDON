POSEIDEN

The backlog hygiene your Product Owner used to keep - automated and self-hosted.

Work comes in never-ending waves. POSEIDON helps you see them, sort them, and show what's adrift: it polls your work tracker (Azure DevOps, GitHub, or GitLab) and your CI pipelines on a schedule, validates work items against configurable tag & state rules, surfaces what needs attention, and reports on work-item + pipeline flow over time.

Launch in browser → Download View on GitHub

The browser client needs a running POSEIDON instance. On a hosted instance it just works; on this static site, launch it and set your instance URL in Settings.

Hygiene rules in config

Required tags, allowed / denied lists, untagged detection, and per-state staleness ("In Progress > 5 days is stale") - all defined in TOML, not code.

Pipeline health

Pass / fail / running counts, last-failure timestamps, and quick links to logs for the pipelines your team owns.

Flow reporting

Work items opened & closed per period grouped by tag, and pipeline success rate over any date range.

One app, everywhere

The same UI ships as a web instance, a desktop app, and a mobile app. Repoint any client at your hosted instance in one setting.

Provider-agnostic

Azure DevOps, GitHub, and GitLab are supported today; Jira and Linear are the next provider plug-ins away. The core doesn't care where a work item came from.

Portable & self-hosted

A token with read scopes is all it needs. Runs standalone, in a container, or fully portable from a USB stick - never writing outside its own paths.
